# ☕ cafe-landing

가상의 동네 카페 '모닝빈'을 소개하는 간단한 랜딩 페이지 예제입니다.
HTML과 CSS만으로 만들어져 있어 별도의 설치나 빌드 없이 바로 열어볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (상단 메뉴, 첫 화면, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 디자인 스타일 (모바일 화면 대응 포함) |

## 사용 방법

1. 이 레포를 클론하거나 내려받습니다.
2. `index.html`을 브라우저(크롬 등)에서 엽니다.

## 수정 방법

- 카페 이름, 메뉴, 가격, 주소는 `index.html`에서 바꿀 수 있습니다.
- 색상과 레이아웃은 `style.css`에서 바꿀 수 있습니다.
